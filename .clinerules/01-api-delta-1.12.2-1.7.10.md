## API Delta Rulebook — 1.12.2 → 1.7.10

| System             | 1.12.2                                                                                                              | 1.7.10                                                                                                                                                                                                           |
|--------------------|---------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Registration       | `RegistryEvent.Register<T>`, `ResourceLocation` registry names via `setRegistryName()`                              | Direct `GameRegistry.registerBlock()` / `registerItem()` calls in preInit/init, no registry events                                                                                                               |
| Block state        | `IBlockState` + `BlockStateContainer`, JSON blockstate files                                                        | Raw `int` metadata (0–15) via `world.getBlockMetadata(x,y,z)` / `setBlockMetadataWithNotify`                                                                                                                     |
| Coordinates        | `BlockPos` (immutable object)                                                                                       | Separate `int x, int y, int z` params everywhere                                                                                                                                                                 |
| Rendering/models   | JSON models + blockstates, `ModelLoader`, baked models                                                              | `IIcon` + `registerBlockIcons`/`registerIcons`, custom renderers via `ISimpleBlockRenderingHandler` / `RenderingRegistry`                                                                                        |
| Entity/TE data     | Capability system (`ICapabilityProvider`)                                                                           | `IExtendedEntityProperties`, registered via event on the entity                                                                                                                                                  |
| Recipes            | JSON recipes in `assets/modid/recipes/`                                                                             | Code-only: `GameRegistry.addRecipe` / `addShapedRecipe` / `addShapelessRecipe`                                                                                                                                   |
| Loot/drops         | Loot table JSON                                                                                                     | `Block#getDrops` / `quantityDropped` / `damageDropped` in code                                                                                                                                                   |
| Achievements       | Advancement JSON system                                                                                             | Old `Achievement`/`StatBase` API (usually stub — low value to port)                                                                                                                                              |
| FML package        | `net.minecraftforge.fml.*`                                                                                          | `cpw.mods.fml.*` (namespace split happened between 1.7.10 and 1.9.4)                                                                                                                                             |
| Networking         | `SimpleNetworkWrapper` / `IMessage`                                                                                 | Same pattern, present in both — one of the few systems that ports ~1:1                                                                                                                                           |
| Direction/facing   | `EnumFacing` (didn't exist pre-1.8)                                                                                 | `net.minecraftforge.common.util.ForgeDirection`, ordinals 0–5 (+ `UNKNOWN`), used directly as block metadata                                                                                                     |
| Empty ItemStack    | `ItemStack.EMPTY` sentinel + `stack.isEmpty()` (introduced 1.11, SRG `func_190926_b`/`field_190927_a` on older obf) | No sentinel — `stack == null` checks, `null` in place of `ItemStack.EMPTY`                                                                                                                                       |
| Event subscription | `@Mod.EventBusSubscriber` (class-level) + `@SubscribeEvent` (static handler), auto-discovered by FML                | No annotation-driven discovery — explicit `MinecraftForge.EVENT_BUS.register(instance)` call (usually in `preInit`), handler methods still `@SubscribeEvent` but on an instance that must be registered manually |
| MCP mappings       | Different mapping set entirely                                                                                      | Different mapping set entirely — even unrelated vanilla methods may have different mapped names; **not** a clean search-replace job, expect compile-driven discovery                                             |

### Verification status of specific SRG names

Rows above and in mod-specific tables sometimes cite exact 1.12.2 SRG method names (`func_xxxxx_x`). Treat these
per the "never guess" standing rule: `ItemStack.func_190926_b`/`field_190927_a`, `World.func_180495_p`,
`World.func_175625_s`, and `World.func_180501_a` are well-established/commonly cross-referenced mappings. Any
other `func_xxxxx_x` name encountered in a mod-specific plan (e.g. `TileEntity.func_190560_a`,
`World.func_175713_t`, `World.func_175704_b`) could not be confirmed against a real MCP export from inside this
repo (no decompiled Forge/FML source is checked in, only the StorageDrawers dependency under
`migrate/storagedrawers/`) — flag these as unverified leads in whichever mod-specific doc cites them, and confirm
via IDE decompiler/javadoc before relying on them during implementation.
